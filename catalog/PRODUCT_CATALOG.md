## Metric Type Reference

| Type | Description |
|------|-------------|
| Conversion | Client acquired/opened product |
| Activation | Client activated/started using product |
| Share of Wallet | Client usage, balance, transactions |
| Engagement | Client interaction (email, digital, branch) |
| Retention | Client kept product, didn't attrit |
| Profitability | Revenue/margin metrics |
