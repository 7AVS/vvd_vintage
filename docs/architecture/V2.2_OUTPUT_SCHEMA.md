# Vintage Engine v2.2 Output Schema

**Created:** 2026-01-23
**Purpose:** Document the v2.2 output schema and design decisions

---

## Output Schema

### vintage_curves.csv

| Column | Type | Description |
|--------|------|-------------|
| MNE | STRING | Campaign mnemonic (VCN, VDA, VAW, etc.) |
| COHORT | STRING | Treatment start month (YYYY-MM) |
| TST_GRP_CD | STRING | Test group code (raw from tactic table) |
| RPT_GRP_CD | STRING | Report group code (raw from tactic table) |
| METRIC | STRING | Metric type (PRIMARY, SECONDARY, EMAIL_OPEN, EMAIL_CLICK) |
| DAY | INTEGER | Days since treatment start (0-indexed, cumulative) |
| WINDOW_DAYS | INTEGER | Treatment window length (median) |
| CLIENT_CNT | BIGINT | Count of unique clients in cell |
| SUCCESS_CNT | BIGINT | Cumulative successes through DAY |
| RATE | DOUBLE | SUCCESS_CNT / CLIENT_CNT * 100 |

### channel_breakdown.csv

| Column | Type | Description |
|--------|------|-------------|
| MNE | STRING | Campaign mnemonic |
| COHORT | STRING | Treatment start month |
| TST_GRP_CD | STRING | Test group code |
| RPT_GRP_CD | STRING | Report group code |
| CHANNEL | STRING | Channel code from TACTIC_CELL_CD |
| CLIENT_CNT | BIGINT | Client count |
| SUCCESS_CNT | BIGINT | Success count |
| RATE | DOUBLE | Success rate |

## Key Design Decisions

### 1. Raw Codes, No Semantic Layer (Phase 1)

- `TST_GRP_CD` and `RPT_GRP_CD` are passed through as-is from tactic table
- No mapping to TEST/CONTROL or human-readable labels
- Dashboard shows raw codes (TG1, TG4, TG7, PSLCRG01, etc.)
- Semantic layer (labels like "Offer 1", "Digital Only") will be added in Phase 2

### 2. No Lift Calculation in Engine

- Engine outputs raw rates per cell
- Dashboard calculates lift by comparing selected groups
- Allows flexible comparisons without pre-computing all pairs
- Control identification is user's choice in dashboard

### 3. METRIC Column

Allowed values:
- `PRIMARY` - Primary success metric from campaign config
- `SECONDARY` - Secondary metric (if defined)
- `EMAIL_OPEN` - Email open rate (denominator = sent)
- `EMAIL_CLICK` - Email click rate (denominator = sent)

### 4. Cumulative DAY Semantics

- DAY=0 means treatment start
- DAY=30 means cumulative successes through day 30
- Not incremental (successes on that day only)

### 5. Engagement Folded into Main Output

- EMAIL_OPEN and EMAIL_CLICK are rows in vintage_curves.csv
- Denominator for engagement = clients who received email (EMAIL_SENT=1)
- Same grain as primary/secondary metrics

### 6. Channel Breakdown Kept Separate

- Different grain (by CHANNEL)
- No daily curves for channel breakdown
- Summary only (total by cohort/cell/channel)

## Dashboard Design

### View 1: Test Group Comparison

- Compare test groups (TG1 vs TG4 vs TG7)
- Filter by Report Group (optional)
- Shows multiple lines on same chart
- Summary table with final day rates

### View 2: Report Group Comparison

- Compare report groups (PSLCRG01 vs PSLCRG03)
- Filter by Test Group (optional)
- Shows multiple lines on same chart
- Summary table with final day rates

## Changes from v2.1

| Aspect | v2.1 | v2.2 |
|--------|------|------|
| Grouping | COHORT, GROUP (TEST/CONTROL) | COHORT, TST_GRP_CD, RPT_GRP_CD |
| Lift | Calculated in engine | Dashboard calculates |
| METRIC column | No | Yes (PRIMARY, SECONDARY, EMAIL_OPEN, EMAIL_CLICK) |
| Engagement | Separate output | Folded into vintage_curves |
| Summary | generate_summary() with lift | Removed (dashboard shows) |
| CI calculation | In engine | Removed |
