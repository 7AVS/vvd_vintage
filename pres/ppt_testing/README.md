# PPT Testing Ground

This folder contains experiments for MVD → PowerPoint generation.

## Approach
1. **Source of truth:** `../VINTAGE_AUTOMATION_MVD.md`
2. **Framework:** Diagram-first thinking → PPT translation
3. **Style:** Minimalist color usage

## Files
- `VISUAL_FRAMEWORK.md` - Diagram-first MVD with visual flows
- `generate_pptx_v2.py` - Minimalist PPT generator
- `VINTAGE_AUTOMATION_v2.pptx` - Output

## Color Philosophy
- White/light gray backgrounds
- Dark blue for text (primary)
- Color used sparingly for emphasis only
- Borders > Fills (most of the time)
- Full color = key callouts only
